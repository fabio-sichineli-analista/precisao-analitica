# Site do Instituto PRECISÃO (Precisão Analítica)

## Sobre o projeto
Site institucional de Fábio Sichineli / Instituto PRECISÃO. Páginas estáticas em HTML,
publicadas pelo GitHub Pages.

- Domínio: https://precisaoanalitica.com.br (definido no arquivo `CNAME` — não apagar)
- Branch principal: `main`
- `.nojekyll` — arquivo necessário para o GitHub Pages servir os arquivos como estão (não apagar)

## Páginas
- `index.html` — página inicial (INSTITUTO PRECISÃO)
- `metodo.html` — Método PRECISÃO
- `principios.html` — A estrutura precede a compreensão
- `Principio.html` — versão parecida de `principios.html` (verificar com o usuário antes de mexer
  ou apagar; não está linkada pelas outras páginas)
- `aplicacao.html` — Aplicação
- `publicacao-01.html` — A fragilidade estrutural do pensamento
- `clareza-do-pensamento.html` — Clareza do Pensamento
- `portfolio.html` — Portfólio; `docs/portfolio.pdf` — portfólio em PDF
- `fundo.jpg` — imagem de fundo

## Regras ao editar
- Ao criar ou renomear uma página, atualizar os links nas outras páginas (a maioria aponta para `index.html`)
- Manter o mesmo visual entre as páginas
- Nomes de arquivo em minúsculas e sem acento

## Projetos relacionados
- Cartão de visita: repositório `business-card` (cartao.precisaoanalitica.com.br)
- Portfólio de dados: repositório `data-analytics-portfolio`

## Preferências
- Responder e escrever sempre em português do Brasil
